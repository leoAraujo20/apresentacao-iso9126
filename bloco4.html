04.4 // O QUE É O TESTLINK?

TestLink: gestão de testes de software

Sistema web open source para organizar o trabalho de teste: planeja, executa e registra resultados, base das métricas externas.

📁

Casos & Suítes

Especificação organizada em árvore de testes.

🗓️

Planos & Builds

Define o que testar em cada versão.

▶️

Execução

Registra sucesso, falha ou bloqueio de cada caso.

📈

Relatórios

Métricas de cobertura e taxa de falhas, com rastreio de requisitos.

⚠️ FERRAMENTA LEGADA

Antiga e sem novas atualizações

O projeto não recebe mais atualizações: a interface é datada e não há novos recursos nem correções recentes.

  • ✔ Ainda útil para entender os conceitos de gestão de testes.
  • ✘ Pouco indicada para projetos novos em produção.
  • ➜ Alternativas modernas: Xray, Zephyr, TestRail, Kiwi TCMS.
